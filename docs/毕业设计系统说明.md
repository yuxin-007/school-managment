# 毕业设计系统说明

## 一、课题名称建议

学校组织与人员管理系统的设计与实现

## 二、课题背景

在学校日常管理中，组织结构复杂，涉及学校、学院、教职工和学生等多类主体。传统的信息管理方式往往存在数据分散、权限边界不清、业务模块割裂等问题。为了提高管理效率，有必要设计一个以组织结构为核心的数据管理系统，实现组织、人员与业务的一体化管理。

## 三、系统目标

本系统的主要目标如下：

- 构建清晰的组织树结构，统一描述学校组织层级
- 支持组织节点的增删改查及人员分配
- 实现基于角色和组织范围的数据权限控制
- 将课程、请假、考勤、公告、成绩等模块与组织树联动
- 提供清晰的前后端分层结构，便于展示与论文撰写

## 四、系统功能模块

### 1. 组织管理模块
- 维护组织树节点
- 管理节点层级关系
- 分配用户到指定组织节点
- 展示组织统计信息

### 2. 用户管理模块
- 用户新增、编辑、删除
- 按角色管理用户信息
- 展示用户统计结果
- 维护学生、教职工、管理员信息

### 3. 课程管理模块
- 创建课程
- 维护课程信息
- 学生选课与退课
- 教师查看本人课程
- 管理员查看组织范围内课程

### 4. 请假管理模块
- 用户提交请假申请
- 管理员审批请假申请
- 查看请假历史记录
- 按组织范围限制审批数据

### 5. 考勤管理模块
- 用户打卡
- 查看个人考勤记录
- 管理员查看组织范围内考勤统计

### 6. 公告管理模块
- 发布公告
- 置顶公告
- 查看公告列表
- 管理员管理公告内容

### 7. 成绩管理模块
- 录入课程成绩
- 学生查看成绩
- 按课程维护成绩数据

## 五、角色权限设计

### 1. 系统管理员
- 管理全部用户和组织节点
- 查看全校业务数据
- 管理课程、考勤、公告等全局信息

### 2. 学院管理员
- 管理本学院组织范围内的数据
- 维护本学院人员、课程、请假审批和考勤信息

### 3. 教职工
- 维护与本人相关的课程、考勤、请假等信息
- 查看本人业务数据

### 4. 学生
- 查看个人课程、课表、成绩
- 提交请假申请
- 进行选课与退课

## 六、技术实现说明

### 后端技术
- Flask：构建 Web 应用和接口服务
- SQLAlchemy：实现数据库对象关系映射
- Flask-Login：实现登录认证
- Flask-Migrate：管理数据库迁移

### 前端技术
- React：实现组件化页面开发
- TypeScript：增强前端类型安全
- Vite：进行前端构建
- Ant Design：实现后台管理界面
- Zustand：管理登录状态和用户信息

## 七、数据库设计建议

论文中可重点分析以下实体：

- 用户表
- 组织节点表
- 用户组织关系表
- 课程表
- 课程安排表
- 选课表
- 请假申请表
- 考勤表
- 公告表
- 成绩表

数据库设计时建议说明：

- 主键与外键关系
- 用户与组织节点的多对多关系
- 课程与教师、学生之间的关系
- 请假与审批流程的数据结构

## 八、系统特色

- 以组织树为核心主数据，结构清晰
- 业务模块与组织权限联动，逻辑完整
- 页面简洁，适合毕业设计展示
- 代码分层较清楚，便于论文阐述系统实现过程

## 九、论文撰写建议

论文可以按以下顺序撰写：

1. 绪论
2. 需求分析
3. 系统总体设计
4. 数据库设计
5. 系统详细实现

7. 总结与展望

其中“系统详细实现”一章可以重点描述：

- 登录与权限控制实现

- 用户与组织归属实现
- 课程、请假、考勤等模块实现
- 前后端接口联动实现
