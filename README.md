# 学校组织与人员管理系统

本项目是一个面向毕业设计的学校组织与人员管理系统，核心目标是围绕“组织树”完成组织结构管理、人员归属管理以及课程、请假、考勤、公告等业务模块的联动。

## 1. 项目定位

- 适用场景：毕业设计、课程设计、系统分析与设计类论文
- 核心思路：以组织树作为主数据，统一管理学校、学院、学生和教职工
- 设计目标：结构清晰、功能完整、便于演示、便于论文撰写

## 2. 核心功能

- 组织树管理：维护学校组织层级，支持添加节点、删除节点、分配人员
- 人员管理：管理学生、教职工、管理员账号与组织归属
- 课程管理：按组织范围查看课程、创建课程、维护课程信息
- 请假管理：提交请假申请、审批请假流程、查看请假状态
- 考勤管理：学生与教职工打卡、管理员查看考勤统计
- 公告管理：发布公告、查看公告、按权限管理公告范围
- 成绩管理：录入成绩、查看成绩、按课程维护成绩信息

## 3. 角色设计

- 系统管理员：管理全校范围的数据与组织结构
- 学院管理员：管理本学院组织范围内的人员与业务
- 教职工：查看和维护与本人相关的课程、考勤、请假信息
- 学生：查看课程、课表、成绩并提交请假申请

## 5. 项目结构

```text
school_management/
├── app/                  # 后端应用
│   ├── blueprints/       # 路由与接口模块
│   ├── services/         # 业务服务层
│   ├── utils/            # 工具与权限辅助
│   ├── models.py         # 数据模型
│   └── __init__.py       # 应用初始化
├── frontend/             # 前端项目
│   ├── src/api/          # 接口封装
│   ├── src/pages/        # 页面模块
│   ├── src/layouts/      # 页面布局
│   ├── src/router/       # 路由配置
│   └── src/store/        # 状态管理
├── docs/                 # 项目文档
├── migrations/           # 数据库迁移
├── init_db.py            # 初始化数据库
└── run.py                # 启动入口
```

## 6. 快速启动

### 安装依赖
后端依赖：
```bash
pip install -r requirements.txt
```

前端依赖：
```bash
cd frontend
npm install
```

### 初始化数据库
```bash
python init_db.py
```

### 启动系统
```bash
python run.py
```

浏览器访问：

[http://127.0.0.1:5000](http://127.0.0.1:5000)
